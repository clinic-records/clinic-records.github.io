# 🏥 نظام سجلات المرضى بالعيادة (Clinic Patient Records System)

نظام محلي متكامل وخفيف جداً لإدارة بيانات وسجلات المرضى بالعيادة الطبية، مصمم بمعمارية معيارية للمؤسسات **(Clean Enterprise Architecture)** لمعالجة ملايين السجلات بسرعة فائقة في أجزاء من الألف من الثانية، مع إتاحة الاستخدام المشترك عبر الشبكة المحلية (LAN) والتحديث التلقائي المباشر.

---

## 🌟 أبرز مميزات المنظومة

1. **إدارة متكاملة لبيانات وسجلات المرضى (CRUD & Profiles):**
   - تسجيل المريض، رقم الملف، الهاتف، الرقم القومي، النوع، التشخيص الطبي، والملاحظات.
   - كود ملف تلقائي فريد لكل مريض (مثل `CL-000001`).
   - سلة مهملات متطورة (Recycle Bin) تدعم الحذف الناعم (Soft Delete)، والاستعادة، والحذف النهائي، مع إمكانية التحديد الجماعي (Batch Operations).

2. **الصور الشخصية وقص وتدوير الصور (Avatar & Cropper System):**
   - صور ملونة برمجية بالأحرف الأولى لتمييز المرضى.
   - إمكانية رفع وتعيين صورة شخصية مع نافذة قص واقتصاص دائرية مدمجة تدعم التكبير، التحريك، والتدوير 90 درجة.

3. **الملفات الطبية الخمسة لكل مريض:**
   - **ملف منفصل (PDF):** رفع، استبدال، استعراض داخل البرنامج، تنزيل، وحذف.
   - **ملف برنامج (PDF):** رفع، استبدال، استعراض داخل البرنامج، تنزيل، وحذف.
   - **ملف اختبارات (PDF):** رفع، استبدال، استعراض داخل البرنامج، تنزيل، وحذف.
   - **ملف الخطة السلوكية (PDF):** رفع، استبدال، استعراض داخل البرنامج، تنزيل، وحذف.
   - **ملف الفيديوهات (مجموعة تسجيلات):** إمكانية رفع عدة فيديوهات بدقة عالية مع شريط تقدم للرفع، ومشغل فيديو مدمج يدعم تدفق الوسائط (HTTP 206 Streaming) دون تحميل الفيديو في الذاكرة.

4. **معمارية بيانات فائقة الأداء (High-Performance Repository Pattern):**
   - **قاعدة بيانات SQLite محلية** داخل مجلد المشروع (`data/clinic.db`)، تعمل بوضع `WAL Mode` وسرعة تزامن عالية `NORMAL synchronous`.
   - **محرك بحث فوري FTS5:** مع خوارزمية **تطبيع النصوص العربية (Arabic Normalizer)** تضمن العثور على المريض فوراً مهما كانت كتابة الهمزات (أحمد / احمد) أو التاء المربوطة (فاطمة / فاطمه) أو الألف المقصورة (منى / مني).
   - **تخزين مجزأ (Sharded Storage):** تقسيم مجلدات المرضى تلقائياً إلى شرائح لمنع تراكم ملايين المجلدات في مسار واحد ولضمان سرعة القرص الصلب.
   - **Direct Disk Streaming:** كتابة الفيديوهات المرفوعة مباشرة إلى الهارد ديسك لمنع استهلاك ذاكرة الـ RAM.

5. **المزامنة اللحظية واكتشاف التزامن (Real-Time SSE):**
   - عداد مباشر لعدد المستخدمين المتصلين في نفس اللحظة عبر أجهزة العيادة.
   - تنبيهات التعارض الفوري عند فتح أو تعديل نفس ملف المريض من أكثر من جهاز في نفس اللحظة.
   - إشعار فوري وتحديث تلقائي لجميع الشاشات عند تعديل بيانات أو استعادة نسخة احتياطية.

6. **الربط بالشبكة المحلية (LAN & QR Code):**
   - السيرفر يكتشف الـ IP المحلي للجهاز تلقائياً (مثلاً `http://192.168.1.15:3000`).
   - يعرض كود **QR Code** في واجهة البرنامج وفي شاشة الأوامر ليتمكن أي طبيب أو ممرض من مسح الكود بكاميرا الموبايل أو التابلت لفتح النظام فوراً.
   - فتح المتصفح الافتراضي تلقائياً عند تشغيل السيرفر.
   - التبديل التلقائي للمنافذ في حال كان المنفذ 3000 مشغولاً.

7. **النسخ الاحتياطي والاستعادة التأمينية (Hot Backup & Safe Restore):**
   - **نسخ احتياطي لحظي بنقرة واحدة:** ينشئ نسخة مطابقة فورية من قاعدة البيانات دون إيقاف السيرفر.
   - **استعادة آمنة:** يقوم النظام بأخذ نسخة احتياطية تأمينية تلقائياً قبل تطبيق أي استعادة لحماية البيانات من أي خطأ بشري.

8. **التحديث التلقائي المباشر (In-Place Auto-Update):**
   - فحص وتثبيت التحديثات الجديدة تلقائياً من GitHub Releases دون الحاجة لإعادة تنصيب البرنامج يدوياً.
   - شريط تقدم مباشر مع أخذ نسخة تأمينية لقاعدة البيانات قبل تطبيق التحديث.

## 🏛️ المعمارية البرمجية (Clean Enterprise Architecture)

تمت هيكلة المشروع وفق معايير المؤسسات الصارمة:

```text
clinic-patient-records/
├── src/
│   ├── config.ts                    # إعدادات النظام ومسارات التخزين
│   ├── server.ts                    # نقطة الانطلاق وإعدادات Fastify
│   ├── db/
│   │   ├── types.ts                 # الكيانات والنماذج البرمجية المستقلة
│   │   ├── connection.ts            # إدارة الاتصال وإعدادات WAL ومحرك FTS5
│   │   ├── database.ts              # الـ Facade الموحد للتنسيق بين المستودعات
│   │   └── repositories/
│   │       ├── patients.repo.ts     # مستودع بيانات وعمليات وبحث المرضى
│   │       ├── documents.repo.ts    # مستودع مستندات الـ PDF الطبية
│   │       ├── videos.repo.ts       # مستودع تسجيلات الفيديو
│   │       └── stats.repo.ts        # مستودع إحصائيات ومؤشرات النظام
│   ├── routes/
│   │   ├── api.ts                   # المنسق العام للمسارات (Route Aggregator)
│   │   ├── system.routes.ts         # مسارات SSE، والشبكة، والتحديثات
│   │   ├── patients.routes.ts       # مسارات المرضى والملفات الشخصية والصور
│   │   ├── documents.routes.ts      # مسارات رفع وتنزيل مستندات الـ PDF
│   │   ├── videos.routes.ts         # مسارات بث ورفع وحذف الفيديوهات
│   │   └── backups.routes.ts        # مسارات النسخ الاحتياطي والاستعادة الآمنة
│   └── utils/
│       ├── arabic.ts                # خوارزميات تطبيع اللغة العربية
│       ├── network.ts               # اكتشاف الـ IP وشبكة الـ LAN
│       ├── realtime.ts              # إدارة أحداث SSE والمتصلين
│       ├── storage.ts               # التخزين المجزأ وتسمية الملفات
│       └── updater.ts               # إدارة التحديثات التلقائية وفك الضغط
├── public/
│   ├── index.html                   # هيكل الواجهة (SPA Declarative DOM)
│   ├── app.css                      # المنسق الرئيسي للتنسيقات
│   ├── css/                         # نظام التنسيقات المجزأ (15 ملفاً مستقلاً)
│   └── js/
│       ├── state.js                 # إدارة الحالة المشتركة للواجهة
│       ├── api.js                   # عميل الاتصال بالسيرفر
│       ├── utils.js                 # دوال التنسيق والإشعارات
│       └── modules/                 # موديولات جافاسكريبت المستقلة (Native ES Modules)
│           ├── table.js             # جدول المرضى وعمليات التحديد
│           ├── filters.js           # شريط البحث والفلاتر والتبويبات
│           ├── patient-form.js      # نموذج إضافة وتعديل المريض
│           ├── patient-details.js   # الملف التعريفي الكامل للمريض
│           ├── cropper.js           # قص وضبط وتدوير الصور
│           ├── videos.js            # رفع ومعاينة الفيديوهات
│           ├── backups.js           # إدارة النسخ الاحتياطية
│           ├── realtime.js          # أحداث الاتصال اللحظي والتعارض
│           ├── updater.js           # واجهة التحديث التلقائي
│           └── modal.js             # التحكم بالنوافذ المنبثقة
```

## 🚀 طريقة التشغيل والأوامر البرمجية

### 1. المتطلبات:
- تثبيت **Node.js** (الإصدار 18 فما فوق).

### 2. التثبيت والتشغيل:
```bash
# تثبيت الحزم (تُنفذ لمرة واحدة فقط)
npm install

# فحص سلامة وتوافقية الوحدات البرمجية والتايب سكريبت (في 60ms)
npm run check

# تشغيل النظام في وضع التطوير
npm run dev

# بناء الحزمة النهائية الموحدة فائقة السرعة
npm run build

# تشغيل الحزمة الإنتاجية المدمجة
npm run prod
```

### 3. التشغيل بالنقر المباشر:
- على **الويندوز:** النقر المزدوج على `start.bat`.
- على **الماك:** النقر المزدوج على `start.command`.

## ⚙️ إعدادات التخزين والمنافذ (`config.json`)

عند أول تشغيل، يُنشئ البرنامج ملف `config.json` تلقائياً، ويمكنك تعديله في أي وقت:
```json
{
  "port": 3000,
  "host": "0.0.0.0",
  "dbPath": "./data/clinic.db",
  "storagePath": "./storage",
  "backupPath": "./backups",
  "autoOpenBrowser": true
}
```
* **نقل التخزين لقرص خارجي:** لحفظ الملفات والفيديوهات على قرص آخر (مثل `D:\ClinicStorage`)، يكفي فقط تغيير مسار `"storagePath": "D:\\ClinicStorage"` وسيعمل البرنامج بسلاسة.
