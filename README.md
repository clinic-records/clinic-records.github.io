# 🏥 نظام سجلات المرضى بالعيادة (Clinic Patient Records System)

نظام محلي متكامل وخفيف جداً لإدارة بيانات وسجلات المرضى بالعيادة الطبية، مصمم لمعالجة ملايين السجلات بسرعة فائقة في أجزاء من الألف من الثانية، مع إتاحة الاستخدام المشترك عبر الشبكة المحلية (LAN) وفتح البرنامج تلقائياً على المتصفح.

---

## 🌟 أبرز مميزات النظام

1. **إدارة متكاملة لبيانات المرضى (CRUD):**
   - تسجيل المريض، رقم الملف، الهاتف، الرقم القومي، التشخيص الطبي، والملاحظات.
   - كود ملف تلقائي فريد لكل مريض (مثل `CL-000001`).

2. **الملفات الطبية الخمسة لكل مريض:**
   - **ملف منفصل (PDF):** رفع، استبدال، استعراض داخل البرنامج، تنزيل، وحذف.
   - **ملف برنامج (PDF):** رفع، استبدال، استعراض داخل البرنامج، تنزيل، وحذف.
   - **ملف اختبارات (PDF):** رفع، استبدال، استعراض داخل البرنامج، تنزيل، وحذف.
   - **ملف الخطة السلوكية (PDF):** رفع، استبدال، استعراض داخل البرنامج، تنزيل، وحذف.
   - **ملف الفيديوهات (مجموعة تسجيلات):** إمكانية رفع عدة فيديوهات بدقة عالية مع شريط تقدم للرفع، ومشغل فيديو مدمج يدعم تدفق الوسائط (HTTP 206 Streaming) دون تحميل الفيديو في الذاكرة.

3. **معمارية مخصصة لملايين المرضى (High-Performance Architecture):**
   - **قاعدة بيانات SQLite محلية** داخل مجلد المشروع (`data/clinic.db`)، تعمل بوضع `WAL Mode` عالي السرعة.
   - **محرك بحث فوري FTS5:** مع خوارزمية **تطبيع النصوص العربية (Arabic Normalizer)** تضمن العثور على المريض فوراً مهما كانت كتابة الهمزات (أحمد / احمد) أو التاء المربوطة (فاطمة / فاطمه) أو الألف المقصورة (منى / مني).
   - **تخزين مجزأ (Sharded Storage):** تقسيم مجلدات المرضى تلقائياً إلى شرائح لمنع تراكم ملايين المجلدات في مسار واحد ولضمان سرعة القرص الصلب.
   - **Direct Disk Streaming:** كتابة الفيديوهات المرفوعة مباشرة إلى الهارد ديسك لمنع استهلاك ذاكرة الـ RAM.

4. **الربط بالشبكة المحلية (LAN & QR Code):**
   - السيرفر يكتشف الـ IP المحلي للجهاز تلقائياً (مثلاً `http://192.168.1.15:3000`).
   - يعرض كود **QR Code** في واجهة البرنامج وفي شاشة الأوامر ليتمكن أي طبيب أو ممرض من مسح الكود بكاميرا الموبايل أو التابلت لفتح النظام فوراً.
   - فتح المتصفح الافتراضي تلقائياً عند تشغيل السيرفر.
   - التبديل التلقائي للمنافذ في حال كان المنفذ 3000 مشغولاً.

5. **أمان البيانات والطباعة:**
   - **نسخ احتياطي لحظي (Hot Backup) بنقرة واحدة:** ينشئ نسخة مطابقة فورية من قاعدة البيانات دون إيقاف السيرفر.
   - **طباعة كارت المريض:** تنسيق طبي جاهز للطباعة المباشرة لبيانات المريض وحالة ملفاته.
   - **الوضع الداكن والفاتح (Dark / Light Mode)**.

## 🚀 طريقة التشغيل

### 1. المتطلبات:
- تثبيت **Node.js** (الإصدار 18 فما فوق).

### 2. التثبيت والتشغيل:
```bash
# تثبيت الحزم (تُنفذ لمرة واحدة فقط)
npm install

# تشغيل النظام في وضع التطوير
npm run dev

# أو التشغيل المباشر للإنتاج
npm start
```

### 3. التشغيل بالنقر المباشر:
- على **الويندوز:** النقر المزدوج على `start.bat`.
- على **الماك:** النقر المزدوج على `start.command`.

---

## ⚙️ إعدادات التخزين والمنافذ (`config.json`)

عند أول تشغيل، يُنشئ البرنامج ملف `config.json` تلقائياً، ويمكنك تعديله في أي وقت:
```json
{
  "port": 3000,
  "host": "0.0.0.0",
  "dbPath": "./data/clinic.db",
  "storagePath": "./storage",
  "backupPath": "./backups",
  "autoOpenBrowser": true
}
```
* **نقل التخزين لهارد خارجي:** إذا أردت حفظ الملفات والفيديوهات على قرص آخر (مثل `D:\ClinicStorage`)، يكفي فقط تغيير قيمة `"storagePath": "D:\\ClinicStorage"` وسيعمل البرنامج بسلاسة.
