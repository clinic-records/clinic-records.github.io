# 🏥 نظام سجلات المرضى بالعيادة (Clinic Patient Records System)

نظام متكامل، محلي وخفيف جداً، مصمم بمعمارية معيارية للمؤسسات **(Clean Enterprise Architecture)** لإدارة بيانات وسجلات وتاريخ المرضى في العيادات الطبية، مع قدرة فائقة على معالجة ملايين السجلات في أجزاء من الألف من الثانية، ودعم كامل للعمل المتزامن عبر أجهزة وشاشات العيادة المتصلة بالشبكة المحلية (LAN) والتحديث التلقائي المباشر دون الحاجة لأي خوادم خارجية أو اشتراكات سحابية.

---

## 🌟 أبرز مميزات المنظومة

### 1. تطبيقات مكتبية محمولة بالكامل (Zero-Prerequisites Portable Apps)
* **ويندوز (Windows):** تطبيق محمول جاهز للتشغيل المباشر (`Clinic Records.exe`) مدمج به خادم التطبيق، وأيقونة صينية النظام (System Tray)، ونافذة تحكم أنيقة تعرض الـ QR Code وعنوان الشبكة وإحصائيات المتصلين اللحظية، دون الحاجة لتثبيت Node.js أو أي برامج مسبقة.
* **ماك (macOS):** تطبيق أصلي مبني بلغة Swift وواجهات Cocoa (`Clinic Records.app`) متوافق مع معالجات Apple Silicon (M1/M2/M3/M4) ومعالجات Intel، مزود بقائمة شريط الحالة (Menu Bar) ونافذة مراقبة مصاحبة مع التحكم الكامل في الخادم.
* **لينكس (Linux):** حزمة محمولة متكاملة تعمل بأمر واحد (`./start.sh`).

### 2. الربط السلس بالشبكة المحلية والهواتف (Hybrid Zero-Config LAN)
* **رابط دائم سهل الحفظ:** يعمل عبر بروتوكول mDNS المحلي:
  ```text
  http://clinic.local:3000
  ```
* **توجيه تلقائي ذكي (Progressive Auto-Probe):** عند مسح الـ **QR Code** من الهاتف، يفحص المتصفح دعم الجهاز لـ `clinic.local` ويقوم بالتحويل إليه تلقائياً، وفي حال عدم دعمه (مثل بعض أجهزة أندرويد القديمة) يظل على رابط الـ IP المباشر بسلاسة تامة دون أي انقطاع.
* **نسخ آمن للروابط:** دعم نسخ الروابط بنقرة واحدة مع توفير آلية نسخ بديلة مخصصة لبيئات الشبكة المحلية (HTTP Fallback) لضمان العمل على كافة المتصفحات دون الحاجة لشهادات SSL.

### 3. التزامن اللحظي ومنع التعارض (Real-Time SSE & Smart Presence)
* **عداد متصلين فوري وفائق الاستقرار:** تحديث فوري لعدد الأجهزة المتصلة مع مهلة ذكية (2-Second Grace Period) لمنع وميض العداد عند إعادة تحميل الصفحة أو التنقل السريع بين الشاشات.
* **اكتشاف التعارض المباشر:** تنبيه فوري للطبيب أو الموظف في حال قيام جهاز آخر بفتح أو تعديل نفس ملف المريض في الوقت نفسه.
* **نبضات اتصال دورية (Active Heartbeat):** فحص نشط كل 10 ثوانٍ لاكتشاف خروج الأجهزة أو دخول الهواتف في وضع السكون فورياً.

### 4. معمارية بيانات عالية الأداء وتزامن كامل (High-Performance SQLite)
* **تخزين محلي مؤمن:** قاعدة بيانات SQLite محلية داخل مجلد المشروع (`data/clinic.db`).
* **نمط WAL المتطور مع معالجة التزامن:** مضبوطة بنمط `WAL Mode` مع تفعيل `busy_timeout = 10000` (10 ثوانٍ) لإصطاف عمليات الكتابة المتزامنة القادمة من أجهزة الشبكة في طابور منظم لمنع قفل قاعدة البيانات (`SQLITE_BUSY`).
* **محرك بحث فوري FTS5 مع تطبيع اللغة العربية:** محرك بحث نصي كامل يتعامل بذكاء مع الهمزات (أ/إ/ا)، والياء والألف المقصورة (ي/ى)، والتاء المربوطة والهاء (ة/ه).
* **تخزين مجزأ للملفات (Sharded Storage):** تقسيم مجلدات المرضى تلقائياً لمنع تراكم آلاف المجلدات في مسار واحد وللحفاظ على سرعة نظام الملفات.

### 5. إدارة شاملة لملفات وتاريخ المريض الطبية
* **الملف الشخصي والبيانات الأساسية:** كود ملف فريد لكل مريض (مثل `CL-000001`)، الهاتف، الرقم القومي، النوع، والتشخيص الطبي.
* **الصور الشخصية وقص وتدوير الصور:** محرر صور دائري مدمج يدعم التكبير والتدوير 90 درجة مع حفظ نسخ محسنة.
* **المستندات الطبية الأربعة (PDF):**
  - ملف منفصل (PDF).
  - ملف البرنامج العلاجي (PDF).
  - ملف الاختبارات والتحاليل (PDF).
  - الخطة السلوكية والتأهيلية (PDF).
* **أرشيف تسجيلات الفيديو (Video Archive):** رفع فيديوهات عالية الدقة، مع مشغل فيديو مدمج يدعم التدفق الجزئي (HTTP 206 Streaming) لتشغيل الفيديوهات فورياً دون استهلاك الذاكرة العشوائية.
* **سلة مهملات متطورة (Recycle Bin):** دعم الحذف الناعم (Soft Delete) مع استعادة فردية أو جماعية وحذف نهائي مؤمن.

### 6. النسخ الاحتياطي والاستعادة الآمنة (Hot Backup & Safe Restore)
* **نسخ احتياطي لحظي بنقرة واحدة:** إنشاء نسخة طبق الأصل من قاعدة البيانات دون إيقاف السيرفر أو تعطيل المستخدمين.
* **استعادة تأمينية:** أخذ نسخة احتياطية تلقائياً قبل تطبيق أي استعادة لحماية البيانات من الأخطاء البشرية.
* **فتح مجلد النسخ الاحتياطية:** زر مباشر يفتح مجلد الـ Backups في مستكشف ملفات النظام المكتبي.

### 7. التحديث التلقائي الصامت المباشر (In-Place Auto-Update)
* فحص وتنزيل التحديثات الرسمية من GitHub Releases بنقرة واحدة.
* **مشغل تحديث منفصل (Detached Runner):** يغلق العمليات السابقة تلقائياً لفك قفل الملفات، ويستبدل الكود والبرامج التنفيذية في الخلفية بهدوء تام دون أي وميض لشاشات الأوامر السوداء، ثم يُعيد تشغيل التطبيق بالنسخة الجديدة تلقائياً.
* **حماية كاملة لبيانات العيادة:** تظل قاعدة البيانات (`data/clinic.db`)، والمستندات والفيديوهات (`storage/`)، والنسخ الاحتياطية (`backups/`)، والإعدادات (`config.json`) محفوظة ومحمية 100% دون أي مساس بها أثناء التحديث.

## 🏛️ الهيكل المعماري للمشروع (Architecture Overview)

```text
clinic-patient-records/
├── src/
│   ├── config.ts                    # إعدادات النظام ومسارات التخزين
│   ├── server.ts                    # نقطة الانطلاق وإعدادات Fastify
│   ├── db/
│   │   ├── types.ts                 # الكيانات والنماذج البرمجية المستقلة
│   │   ├── connection.ts            # إدارة الاتصال وإعدادات WAL والمهلة ومحرك FTS5
│   │   ├── database.ts              # الـ Facade الموحد للتنسيق بين المستودعات
│   │   └── repositories/
│   │       ├── patients.repo.ts     # مستودع بيانات وعمليات وبحث المرضى
│   │       ├── documents.repo.ts    # مستودع مستندات الـ PDF الطبية
│   │       ├── videos.repo.ts       # مستودع تسجيلات الفيديو
│   │       └── stats.repo.ts        # مستودع إحصائيات ومؤشرات النظام
│   ├── routes/
│   │   ├── api.ts                   # المنسق العام للمسارات (Route Aggregator)
│   │   ├── system.routes.ts         # مسارات SSE، الشبكة، التحديثات، والنسخ الاحتياطي
│   │   ├── patients.routes.ts       # مسارات المرضى والملفات الشخصية والصور
│   │   ├── documents.routes.ts      # مسارات رفع وتنزيل مستندات الـ PDF
│   │   ├── videos.routes.ts         # مسارات بث ورفع وحذف الفيديوهات
│   │   └── backups.routes.ts        # مسارات النسخ الاحتياطي والاستعادة الآمنة
│   └── utils/
│       ├── arabic.ts                # خوارزميات تطبيع اللغة العربية للبحث الذكي
│       ├── network.ts               # اكتشاف الـ IP وشبكة الـ LAN وتسجيل mDNS
│       ├── realtime.ts              # إدارة أحداث SSE والمتصلين واكتشاف التعارض
│       ├── storage.ts               # التخزين المجزأ وتسمية الملفات
│       └── updater.ts               # إدارة التحديثات التلقائية وفك الضغط والمشغل المنفصل
├── scripts/
│   ├── windows-launcher/           # تطبيق الويندوز المرافق بلغة C# (System Tray & GUI)
│   ├── macos-launcher/             # تطبيق الماك المرافق بلغة Swift (Menu Bar & GUI)
│   ├── build-windows.ps1           # سكريبت بناء حزمة ويندوز المحمولة
│   ├── package-macos.sh            # سكريبت بناء حزم ماك المحمولة (Universal / Apple / Intel)
│   ├── package-linux.sh            # سكريبت بناء حزمة لينكس المحمولة
│   ├── release.mjs                 # أداة النشر الآلي ومزامنة الإصدارات عالمياً
│   └── check-modules.mjs           # فاحص سلامة وحدات ES Modules
├── public/
│   ├── index.html                   # هيكل الواجهة (SPA Declarative DOM)
│   ├── app.css                      # المنسق الرئيسي للتنسيقات
│   ├── css/                         # نظام التنسيقات المجزأ (15 ملفاً مستقلاً)
│   └── js/
│       ├── state.js                 # إدارة الحالة المشتركة للواجهة
│       ├── api.js                   # عميل الاتصال بالسيرفر
│       ├── utils.js                 # دوال التنسيق ونسخ الروابط والإشعارات
│       └── modules/                 # موديولات جافاسكريبت المستقلة (Native ES Modules)
│           ├── table.js             # جدول المرضى وعمليات التحديد
│           ├── filters.js           # شريط البحث والفلاتر والتبويبات
│           ├── patient-form.js      # نموذج إضافة وتعديل المريض
│           ├── patient-details.js   # الملف التعريفي الكامل للمريض
│           ├── cropper.js           # قص وضبط وتدوير الصور
│           ├── videos.js            # رفع ومعاينة الفيديوهات
│           ├── backups.js           # إدارة النسخ الاحتياطية
│           ├── realtime.js          # أحداث الاتصال اللحظي والتعارض والتحديث
│           ├── updater.js           # واجهة شريط تقدم التحديث التلقائي
│           └── modal.js             # التحكم بالنوافذ المنبثقة
```

## 🚀 التشغيل المباشر للنسخ الجاهزة (Production Downloads)

يمكنك تحميل النسخ المحمولة الجاهزة مباشرة من صفحة [GitHub Releases](https://github.com/clinic-records/clinic-records.github.io/releases):

### 🪟 ويندوز (Windows):
1. حمل ملف `ClinicRecords-Windows-x64.zip` وفك الضغط عنه.
2. انقر نقراً مزدوجاً على **`Clinic Records.exe`**.
3. *إذا ظهرت شاشة حماية ويندوز (SmartScreen): اضغط على "More info" ثم "Run anyway".*

### 🍏 ماك (macOS):
1. حمل الملف المتوافق مع جهازك:
   - لأجهزة الماك الحديثة (M1/M2/M3/M4): `ClinicRecords-macOS-AppleSilicon.zip`.
   - لأجهزة الماك بمعالجات إنتل: `ClinicRecords-macOS-Intel.zip`.
2. فك الضغط وافتح تطبيق **`Clinic Records.app`**.
3. *لتجاوز تنبيه الأمان عند أول تشغيل: اضغط بزر الفأرة الأيمن (Right-Click) على التطبيق واختر "Open"، أو شغّل: `xattr -cr "Clinic Records.app"` في Terminal.*

### 🐧 لينكس (Linux):
1. فك الضغط عن `ClinicRecords-Linux-x64.tar.gz`.
2. شغّل الأمر: `./start.sh`.

## 💻 بيئة التطوير والأوامر البرمجية (Developer Guide)

إذا أردت تطوير وتعديل الكود المصدري محلياً:

```bash
# 1. تثبيت الاعتماديات
npm install

# 2. فحص سلامة التايب سكريبت ووحدات الـ ES Modules
npm run check

# 3. تشغيل وضع التطوير السريع مع المراقبة
npm run dev

# 4. بناء الحزمة الإنتاجية الموحدة
npm run build

# 5. تشغيل السيرفر الإنتاجي
npm run prod

# 6. إطلاق إصدار جديد تلقائياً (Patch / Minor / Major)
npm run release -- patch
```

## ⚙️ ملف الإعدادات (`config.json`)

يتم توليد ملف `config.json` تلقائياً عند أول تشغيل بجانب التطبيق:

```json
{
  "port": 3000,
  "host": "0.0.0.0",
  "dbPath": "./data/clinic.db",
  "storagePath": "./storage",
  "backupPath": "./backups",
  "autoOpenBrowser": true
}
```

* **تغيير منفذ الخادم:** يمكنك تعديل `"port"` إلى أي منفذ آخر. علماً بأن السيرفر يبحث تلقائياً عن منفذ بديل شاغر إذا كان 3000 مشغولاً.
* **التخزين الخارجي:** لنقل ملفات المرضى والفيديوهات إلى قرص صلب خارجي أو وحدة تخزين مشتركة (مثل `D:\ClinicData`)، يكفي تعديل قيمة `"storagePath"` وسيتم حفظ كافة المرفقات في المسار الجديد تلقائياً.
